# 04 互联网络层：集群越大，网络越值钱

## 本层回答的问题

为什么几万张 GPU 需要天价网络？铜和光怎么分工？光模块为什么是中国公司
主导而它的"心脏"却卡在美日手里？CPO 会颠覆谁？

## 技术第一性原理

**为什么网络的价值随集群规模超线性增长**：训练时每张 GPU 每一步都要与
其他 GPU 交换梯度（all-reduce），通信量随集群规模增长，而任何一条慢链路
都会拖住整个集群（木桶效应）。十万卡集群中网络成本占比可达系统的 15-20%，
且代际升级速度（800G→1.6T→3.2T，约 2 年一代）快于 GPU 本身。

**两种网络，两套生意**：
- **Scale-up（机柜内）**：72-576 颗 GPU 连成单一计算域，超短距离、极致带宽。
  当前用**铜**（NVLink 铜背板 + 铜缆，便宜、零功耗转换）——这就是"AI 拉动
  铜缆/连接器"的真实含义（APH/TEL/CRDO 的 AEC）。距离超过 ~2 米铜就撑不住，
  Rubin Ultra 的 NVL576 开始引入机柜间光互联；
- **Scale-out（机柜间/跨机房）**：数千机柜组网，必须用**光**。
  协议之争：InfiniBand（NVDA 私有，训练场景占优）vs 以太网（开放阵营
  AVGO Tomahawk/ANET，正在反攻，推理场景占优）。

**光模块解剖**（理解"卡脖子在哪"的关键）：
```
光模块 = 激光器芯片(EML/CW) + DSP芯片 + 封装组装
  │          │                  │
  │          │                  └ 劳动密集 → 中国厂商主导（旭创/新易盛 全球前二）
  │          └ 高端逻辑芯片 → MRVL/AVGO 双寡头
  └ III-V族化合物半导体工艺 → LITE/COHR/三菱/住友 寡头
       └ 衬底材料 InP → 住友电工/AXT(北京通美) —— 中国出口管制名单上
```
**价值与瓶颈倒挂**：组装环节（中国）份额最大但毛利率最低；激光器芯片
（美日）量小但卡脖子——2026 年 NVDA 各投 $20 亿入股 LITE/COHR 锁激光器
供应，800G 模块短缺预计持续到 2027、1.6T 到 2029。

**CPO（共封装光学）= 本层的代际革命**：把光引擎从"可插拔模块"移进交换机
芯片封装内（TSMC COUPE 工艺），省 30%+ 功耗。2026H1 开始上量。
**输赢分布**：可插拔模块厂（旭创/新易盛）远期受威胁；激光器（外置光源
依然需要）中性偏多；光纤阵列 FAU（天孚）与先进封装（TSMC/载板厂）受益；
交换机芯片厂（AVGO）主导权变大。

## 格局与玩家

详见[地图③节](../ai_supply_chain_map.md)。速记：模块=中国双雄+COHR；
激光器=LITE/COHR 寡头；InP 衬底=住友/AXT；DSP=MRVL/AVGO；
scale-up 互联新贵=ALAB（PCIe/Scorpio）；交换机=ANET/AVGO/NVDA 三国杀；
连接器=APH/TEL。

## 经济学特征

- **量价剪刀差**：出货量每代爆增（800G：24M→63M 只），但单价每年降
  15-30%——收入增长靠"代际升级跑赢降价"。**看毛利率方向比看收入增速重要**
  （旭创 Q1'26 毛利率 46% 还在升 = 1.6T 占比提升；新易盛净利环比 -13% =
  800G 降价压力）；
- **认证壁垒 + 客户集中**：进入 NVDA/云厂供应链要 1-2 年认证，但大客户
  （NVDA 占 1.6T 需求 60%）随时可以双源化压价；
- **地缘溢价双向**：中国模块厂有被关税/管制波及的风险；反过来 InP 衬底
  的中国出口管制让 AXT 这类标的同时持有"稀缺溢价"与"管制风险"。

## 投资视角

- 本层增速最陡但**可见度最低**（1.6T 预测差 6 倍），适合"卖铲人"思路：
  与其赌模块厂排位，不如持有代际升级中**用量必然增加且格局稳定**的环节
  （激光器、FAU、测试）——深度报告 Tier 1 里的 LITE/COHR 即此逻辑，
  但 NVDA 入股后估值可能已抢跑，等 screener 验证；
- AXT（AXTI）单独标注：高赔率地缘期权，仓位纪律重于观点；
- 工具：`finloop signals LITE`、`finloop analyze COHR`。
