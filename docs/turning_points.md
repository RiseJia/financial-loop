# 拐点与动量切换：识别逻辑

> 对应实现：`src/finloop/signals/`。
> 运行 `finloop signals <TICKER>` 查看某只股票最近的拐点与动量切换事件。

## 基本认知：拐点无法被"预测"，只能被"分级确认"

任何声称精确预测顶底的方法都不可靠。可行的做法是把拐点理解为**证据逐渐积累的过程**，
并按确认程度分层行动：

```
第一层：动能衰竭     MACD 柱体收缩、RSI/OBV 背离        → 提高警惕、停止加仓
第二层：动量切换     动量得分换向、MACD 穿越零轴          → 减仓/试探性反向
第三层：结构确认     均线交叉、200日线得失、放量突破       → 调整核心仓位
```

层级越早，信号越灵敏但假信号越多；层级越晚，确认度越高但价格已走出一段。
**用早期信号管理风险，用晚期信号调整仓位**，是处理这个矛盾的标准答案。

## 一、本框架检测的拐点类型（turning_points.py）

### 均线交叉类（第三层：结构确认）

| 信号 | 定义 | 强度 | 说明 |
|------|------|------|------|
| 黄金交叉 | 50 日线上穿 200 日线 | ★★★ | 长线牛市结构确立的标志，滞后但极少误报大级别趋势 |
| 死亡交叉 | 50 日线下穿 200 日线 | ★★★ | 长线趋势恶化，历史上多数大熊市此信号都提前出现 |
| 收复/跌破 200 日线 | 价格穿越 200 日线 | ★★ | 第一道防线，需观察能否站稳（防假突破） |
| 中期金叉/死叉 | 20 日线穿越 50 日线 | ★★ | 中期趋势转换，比 50/200 灵敏 |

### MACD 类（第二层：动量切换）

按零轴位置分级是关键：

- **零上金叉**（★★★）：上升趋势中回调结束，金叉中胜率最高的一类；
- **零下金叉**（★）：下跌中的反弹尝试，单独出现不足为凭；
- **零上死叉**（★）：上涨途中歇脚，多数只是休整；
- **零下死叉**（★★★）：下跌趋势再度转弱，杀伤力最大；
- **穿越零轴**（★★）：12 日与 26 日 EMA 的相对位置反转，中期动能正式换主。

### 极端回归类（第一~二层）

- **RSI 超卖回升穿 30 / 超买回落穿 70**：注意是"回归穿越"而不是"正处于极端"——
  处于超卖只说明跌得狠，回升穿越才说明抛压衰竭。

### 波动率压缩突破类（第三层，高质量信号）

- **挤压放量突破**：布林带宽收缩至近半年最低 15% 分位（市场极度安静）之后，
  放量（量比>1.5）突破上/下轨。波动率循环理论下，这是新趋势起点的高质量形态。
  方向由突破方向给出，挤压本身不预测方向。

### 背离类（第一层：最早期预警）

比较最近 30 根与之前 30 根窗口的极值：

- **顶背离**：价格新高，RSI/OBV 高点降低 → 上涨的动能/资金支持在衰减；
- **底背离**：价格新低，RSI/OBV 低点抬高 → 抛压在衰竭。

**背离的正确用法**：它是"减仓、收紧止损、停止加仓"的信号，不是反向开仓信号。
强趋势中背离可以连续出现多次才兑现（甚至不兑现）。

## 二、动量切换的量化定义（momentum_switch.py）

"momentum switching" 在本框架中被定义为一个**四分量投票系统**的换向：

```
动量得分（-4 ~ +4）：
  ① MACD 柱体符号        多头/空头动能          ±1
  ② MACD 柱体斜率        动能在加速还是衰减       ±1
  ③ ROC20 符号           20日动量方向            ±1
  ④ RSI vs 50           中线强弱               ±1

得分 ≥ +2 → 多头动量区
得分 ≤ −2 → 空头动量区
中间      → 过渡区（动量换挡中）
```

**动量切换事件** = 从一个稳定阵营（多头区/空头区）完整换到另一个阵营。
过渡区内的来回抖动不触发事件（用"最近一次稳定阵营"做状态记忆），这是为了过滤噪声。

为什么是这四个分量？它们覆盖了动量的三个维度：

- **方向**（①③④）：多周期、多视角确认动量朝哪边；
- **加速度**（②）：MACD 柱体斜率是动量的二阶导，动能衰减总是先于方向反转出现；
- **互相校验**：MACD 来自均线系统，ROC 是原始收益率，RSI 是涨跌幅之比——三个不同的信息加工路径，同向时可信度乘数提升。

### 切换信号的质量过滤

动量切换初期既可能是新趋势起点，也可能是反弹/回调陷阱。判断质量看三点：

1. **量能配合**：换向伴随放量则可信度高；
2. **市场状态**（ADX）：震荡市中的动量切换大多走不远；
3. **更高周期共振**：日线切换方向与周线趋势一致时胜率显著更高。

## 三、市场状态机（regime.py）：最重要的元规则

在看任何信号之前，先回答"现在是什么市场"：

```
trend_up    上升趋势市   ADX≥25 且 +DI>−DI 且价格在200日线上
trend_down  下降趋势市   ADX≥25 且 −DI>+DI 且价格在200日线下
range       震荡市      ADX<20
turning     转折期      其余（证据互相矛盾）
```

| 状态 | 该用的打法 | 该警惕的陷阱 |
|------|-----------|-------------|
| 上升趋势市 | 顺势持有、回调低吸、移动止盈 | RSI 超买钝化，别逆势做空 |
| 下降趋势市 | 防御、轻仓、快进快出 | 超卖反弹大多是出货机会 |
| 震荡市 | 区间高抛低吸、布林边界 | 金叉死叉反复无效；留意挤压→趋势的转换 |
| 转折期 | 降仓位、缩风险、等确认 | 这是胜率最低的环境，少动手 |

**同一个信号在不同状态下含义完全不同**——这是技术分析最容易被忽视、也最值钱的一课。
例如 RSI=75：上升趋势市里是强势确认，震荡市里是高抛位置。
