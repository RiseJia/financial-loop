# 03 存储层：内存墙、HBM 的本质、为什么存储永远是周期股

## 本层回答的问题

为什么 AI 让存储厂商突然暴利？HBM 和普通内存有什么区别？这种暴利能持续吗？

## 技术第一性原理

**内存墙（memory wall）**：过去二十年算力增长 ~60,000 倍，内存带宽只增长
~100 倍。大模型推理的每个 token 都要把数百 GB 的模型权重从内存搬到计算单元
——**搬运数据的速度，而非计算速度，决定了 AI 芯片的实际产出**。GPU 利用率
低的根本原因通常是"在等数据"。

**HBM（高带宽内存）= 用封装手段绕过内存墙**：把 8-16 层 DRAM die 垂直堆叠、
用硅通孔（TSV，穿透芯片的微米级垂直导线）连接、再与 GPU 封装在同一块中介层
上——距离从厘米级缩到毫米级，并行通道从 64 位扩到 2048 位（HBM4）。
本质：**HBM = DRAM（标准品）+ 先进封装（工艺壁垒）**，这个"+"正是它
毛利率数倍于普通内存的来源，也是键合设备（02篇）爆单的原因。

**技术难点决定竞争格局**：堆 12-16 层意味着每层都要超薄化、TSV 对准精度
要求极高、一层坏全堆报废——**良率即护城河**。SK 海力士领先的本质是
量产良率领先，而非纸面规格。

**分层存储金字塔**（AI 数据中心的完整存储需求）：
HBM（热数据，贴着 GPU）→ 常规 DRAM（服务器内存）→ 企业级 SSD（温数据）
→ nearline HDD（冷数据湖，训练语料归档）。AI 同时拉动了每一层。

## 格局与玩家

- **HBM 三强**：SK 海力士（2026E bit 份额 ~50%）、三星（~28%，HBM4 世代
  重回牌桌）、美光（~22%）。2026-06 黄仁勋确认三家全部通过 NVDA HBM4 认证；
- **挤出效应**（当前阶段最重要的财务机制）：HBM 占用的晶圆与封装产能是
  常规 DRAM 的 3 倍以上（同等 bit）→ 三强把产能倾斜给 HBM → 常规 DRAM
  供给收缩 → **2026Q1 DRAM 价格环比 +90%**。三家的"旧业务"正在经历
  比 HBM 本身更猛的暴利；
- **供给纪律**：2026 年 DRAM capex $61.3B（+14%）但主要投向制程升级而非
  新厂房——三十年来第一次，寡头们在暴利期保持克制（被 2022 年的暴亏教育过）。
  这是本轮与历史周期最大的不同，**也是多头论点中最依赖人性的一环**。

## 经济学特征：为什么存储永远是周期股

存储是**资本品行业里的大宗商品**：产品标准化（你的 DRAM 和我的 DRAM 可互换）
→ 没有定价权，价格由行业供需缺口的边际决定 → 而供给以"一座 $200 亿的厂"
为单位粗粒度跳变，需求连续变化 → **价格永远在暴涨与暴跌之间摆动**。

周期的固定剧本（本轮进行到第 3 步）：
1. 需求冲击（这次是 AI）→ 缺货涨价；
2. 厂商利润暴增，财报"史上最佳"；
3. **所有人宣布扩产**（SK M15X、三星 P4、美光新线——已发生）；
4. 新产能 18-24 个月后集中落地，需求增速恰好放缓；
5. 价格崩塌，全行业亏损，砍产能 → 回到 1。

**估值纪律**：周期股在周期顶的 PE 永远"便宜"（E 是峰值利润）。正确做法是
用**正常化盈利**（跨周期平均）或 P/B 历史分位估值。"低 PE 的存储股"是
价值陷阱的教科书形态——这正是 screener 需要人工复核的地方。

## 投资视角

- 本层"需求>>估值"的形态特殊：**不是错位被忽视，而是市场不敢给周期股
  高估值**——folder 的分歧在"这次是否不同"（HBM 的定制化与长协是否打破了
  大宗商品属性）。诚实的回答：HBM 部分是（与 GPU 平台绑定、年度议价），
  常规 DRAM 部分不是；
- 美光（MU）是美股最纯的载体（披露透明、估值可比）；SK 海力士弹性最大；
  设备侧的"卖铲人"打法（键合/检测，见02篇）周期风险更缓和；
- 工具：`finloop analyze MU`，配合 08 篇的周期框架定位当前位置。
