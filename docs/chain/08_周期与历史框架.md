# 08 周期与历史框架：2000 年光纤的镜子与本轮的判断工具

## 本篇回答的问题

这场盛宴什么时候结束？历史上的同类周期如何收场？用什么客观信号判断
当前位置，而不是靠情绪站队多空？

## 历史镜像一：2000 年光纤泡沫（相似度最高的剧本）

1996-2000 年，互联网流量"每 100 天翻倍"的叙事驱动电信运营商豪掷千亿
铺光纤，设备商（朗讯/北电）与元件商（JDS Uniphase）利润与估值齐飞。
2001 年资本开支断崖，**JDSU 跌 98%，铺下的光纤 85% 长期闲置（dark fiber）**。

与本轮的相似点（警惕清单）：
- 需求叙事真实但**被外推到不可持续的斜率**（互联网流量确实在涨，只是没那么快）；
- **供应商融资（vendor financing）**：朗讯借钱给客户买自己的设备 ≈ 今天
  NVDA 投资 OpenAI/Neocloud、芯片厂入股供应商与客户的循环结构；
- 元件/材料层在顶部前夜最暴利（与今天的上游提价潮同构）。

与本轮的不同点（多头的真实依据）：
- 本轮的买家（四大云厂）**用自有现金流而非债务**支付大部分 capex，资产
  负债表质量与 2000 年的电信运营商不可同日而语；
- GPU 与光纤不同：**会折旧、会过时、需要持续替换**——即使总量见顶，
  替换需求也提供了收入地板（光纤铺完就是铺完了）；
- 推理收入是经常性的、随用量计费的（07篇），而 2000 年的"流量"大部分
  不直接产生收入。

## 历史镜像二：半导体存储周期（节奏参考）

存储三十年的剧本（03篇详述）给出**时间尺度**：从"全行业宣布扩产"到
"价格崩塌"历史上是 18-30 个月。本轮各环节的扩产宣布集中在 2025H2-2026H1
（SK M15X、三星 P4、Ibiden ¥5000亿、Nittobo 三倍化、TSMC AP7/AP8……），
**机械外推的供给海啸到达时间：2027-2028**。这与"CoWoS 供需平衡最早 2027"
的产业共识吻合——2027 是本轮周期排位赛的裁判年。

## 本轮独有的结构风险：循环融资

```
NVDA ──投资──▶ OpenAI/Neocloud ──采购承诺──▶ Oracle/云厂 ──下单──▶ NVDA
```
链条内每一环都把"别人的承诺"记为自己的需求。循环本身不必然是泡沫
（亚马逊早期也靠供应商信用扩张），但它**放大了表观需求、模糊了真实的
外部付费**。监控办法：盯链条里**唯一不能循环的东西——终端付费**（07篇
的覆盖度指标）。

## 判断当前位置的客观信号面板

把 08 篇压缩成一张可操作的表（与深度报告的证伪触发器互为表里）：

| 信号 | 当前状态(2026-06) | 周期顶部特征 |
|------|------------------|--------------|
| 云厂 capex 增速 | +77%，仍在上修 | 增速转负前先"增速放缓"——盯二阶导 |
| 上游提价潮 | 进行中（ABF/T-glass/DRAM/OSAT） | 提价是顶部行为：暴利→扩产→过剩，时滞18-30月 |
| 扩产宣布密度 | 2025H2-2026H1 高峰 | 供给海啸 ETA 2027-28 |
| 循环融资规模 | 扩大中（NVDA 入股上下游） | 顶部前夜通常达到峰值 |
| 终端收入/capex 覆盖度 | 缺口大，靠预期支撑 | 持续恶化 = 最根本的红旗 |
| 黄色信号 | SK 或砍 HBM4 出货 20-30%（已亮） | 单一信号不定性，聚集才定性 |

**使用纪律**：任何单一信号都会误报。规则是——**面板中 ≥3 项同时转向，
即把上游持仓的周期假设从"扩张中段"下调为"扩张尾段"**，对应动作不是清仓，
而是：停止加仓提价逻辑标的、把扩产兑现型换成垄断现金流型、收紧止损。

## 与本 repo 工具的闭环

```
本篇(战略层)     ──什么时候该警惕──▶ 信号面板，季度更新
深度报告(战役层) ──买什么不买什么──▶ Tier 队列 + 证伪触发器
finloop(战术层)  ──何时进出────────▶ regime 状态机 + 拐点/动量信号
                                     （docs/turning_points.md）
```
三层各管一件事：周期框架决定仓位水位，研究队列决定标的池，
技术信号决定执行时点。**最常见的灾难是用战术信号回答战略问题**
（比如用 RSI 超卖去抄一只周期反转股的底）。

## 推荐延伸阅读

- 《Engines That Move Markets》— 技术泡沫史的标准教材（铁路/电报/光纤）；
- 任何一份 2001 年的 JDSU 年报 — 看顶部语言长什么样（"可见度有限"出现前
  一年管理层在说什么）；
- TrendForce/Wood Mackenzie 的季度数据 — 本面板的数据源。
