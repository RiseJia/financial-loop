# 日内交易决策框架

> 对应实现：`src/finloop/strategy/intraday.py`。
> 运行 `finloop intraday <TICKER>` 查看基于 5 分钟线的日内视角。

## 先泼冷水：日内交易的统计现实

绝大多数散户日内交易者长期亏损——不是因为笨，而是因为：交易成本与滑点的复利侵蚀、
与机构算法在毫秒级竞争、情绪在高频决策下指数级放大。
如果以学习为目的，请使用模拟盘或极小仓位，**把单日最大亏损硬性限制在账户的 1% 以内**。

---

## 一、日内三大锚点

### 1. VWAP（成交量加权均价）——日内公允价格

机构执行算法以 VWAP 为基准，使它成为日内最重要的参照系：

- **方向过滤**：价格在 VWAP 上方只考虑做多，下方只考虑做空——单这一条就能过滤一半逆势冲动；
- **回踩入场**：强势股回踩 VWAP 获支撑（缩量踩、放量弹）是日内最经典的顺势买点；
- **偏离回归**：价格急速远离 VWAP 后有回归引力，但"远离可以更远离"，逆势接刀要等K线企稳形态。

### 2. 开盘区间（Opening Range）——前 30 分钟高低点

开盘 30 分钟集中了隔夜信息的消化与机构开仓，其高低点是天然的多空分界：

- **向上突破**区间高点 → 日内多头格局，区间上沿转为支撑（ORB 策略原型）；
- **向下跌破**区间低点 → 日内空头格局；
- **区间内** → 方向未选择，观望优于参与。

突破的质量看：是否放量、突破后是否回踩确认不破、与 VWAP 方向是否一致。

### 3. 昨日高低收——隔夜参照系

昨日最高/最低/收盘是所有日内玩家共同盯着的价位：

- 站上昨高 = 隔夜套牢盘解放，上方阻力真空；
- 跌破昨低 = 触发昨日多头止损，容易加速；
- 围绕昨收窄幅波动 = 市场在等催化剂。

## 二、日内动量：9/21 EMA + 日内 RSI

- 9EMA > 21EMA 且两线向上 → 日内上升节奏，回踩 9/21EMA 是顺势点；
- 日内 RSI 配合判断节奏强弱，但日内 RSI 钝化比日线更频繁，只作辅助。

**信号共振表**（核心打法：只交易多重锚点同向的时刻）：

| VWAP | 开盘区间 | EMA | 决策倾向 |
|------|---------|-----|---------|
| 上方 | 已上破 | 多头 | 高质量做多环境，回调即机会 |
| 上方 | 区间内 | 多头 | 偏多，等突破确认 |
| 混杂 | 区间内 | 混杂 | 不交易（大多数时间属于此类） |
| 下方 | 已下破 | 空头 | 高质量做空/空仓环境 |

## 三、时段特性（美东时间）

| 时段 | 特性 | 适合 |
|------|------|------|
| 9:30–10:30 | 量最大、波动最剧烈、方向多变 | 经验者的主战场；新手最好只观察前 30 分钟 |
| 10:30–14:00 | 量萎缩、易回归 VWAP 震荡 | 均值回归打法；趋势单容易被磨损 |
| 14:00–15:00 | 方向重新选择 | 观察下午突破 |
| 15:00–16:00 | 机构收尾、MOC 订单、量再放大 | 趋势日的最后一段顺势；当日了结 |

## 四、风险纪律（比信号重要十倍）

1. **入场前先定止损**：以 ATR 适配（如 1.5×5 分钟 ATR）或结构位（VWAP/区间边界）放止损，没有止损价就没有这笔交易；
2. **单笔风险 ≤ 账户 0.5%，单日累计亏损 ≤ 1-2% 立即停止当日交易**——防止情绪化连环报复单，这条规则的价值超过所有技术分析；
3. **盈亏比 ≥ 2:1 才入场**：50% 胜率下 2:1 盈亏比长期为正期望；
4. **隔夜不留日内仓**：日内逻辑的仓位留过夜=用错误的理由持有头寸；
5. **记录每一笔**：入场理由、出场理由、情绪状态。复盘日志是日内交易唯一可靠的进步来源。

## 五、数据注意事项

yfinance 的分钟数据有限制：1 分钟线仅最近 7 天、5 分钟线最近 60 天，且有约 15 分钟延迟。
**延迟数据不可用于实盘日内决策**，本模块定位是盘后复盘与形态学习。
实盘需接入实时数据源（Polygon、IBKR API 等），数据层 `finloop.data.market` 已为替换预留了统一接口。
