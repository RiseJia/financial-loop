# 回测原理与执行指南

> 对应实现：`src/finloop/backtest/`。
> 命令：`finloop backtest AAPL --strategy sma200`、`finloop eventstudy AAPL`。

## 一、策略是什么东西的抽象？

剥掉所有术语，一个交易策略就是一个**决策函数**：

```
f: 截至 t 时点你知道的一切  →  t 时点你该持有的仓位
```

"知道的一切"叫**信息集**（价格历史、指标、财报、新闻……），输出就是一个数：
0（空仓）、1（满仓）、0.5（半仓）、-1（做空满仓）。

这个抽象的威力在于它把模糊的"我觉得该买了"强制变成了三个可检验的承诺：

1. **输入封闭**：你只能用 t 时点已经发生的信息。"我当时感觉会涨"不是输入；
2. **输出明确**：仓位是一个数，不是"看好"这种无法执行的态度；
3. **规则恒定**：同样的输入必须给出同样的输出——否则"策略"只是事后叙事。

在本框架的代码里（`backtest/strategy.py`）：

```python
Strategy = Callable[[enrich后的DataFrame], pd.Series]
# 输入：带全部指标的历史行情（行 = 时间）
# 输出：目标仓位序列，position[t] ∈ [0, 1]
```

例如 200 日线策略的完整数学内容只有一行：

```python
position = (close > sma200)        # 线上满仓，线下空仓
```

注意有两类策略：

- **无状态策略**：仓位只取决于当前 bar 的指标值（如 sma200、macd），一行向量化条件即可；
- **有状态策略**：仓位取决于历史路径（如"RSI<30 买入、>55 卖出"——RSI=45 时你是持有还是空仓，取决于你是从 25 涨上来还是从 60 跌下来），必须顺序扫描，见 `strat_rsi_mr` 的循环写法。

同一个函数，喂历史数据 = 回测，喂今天的数据 = 实时决策信号——**没有两套代码**，这是把策略约束成纯函数的最大工程收益（消除"回测里是一套逻辑、实盘手抖又是另一套"的分叉）。

## 二、回测的原理：它在测什么？

回测 = **把策略函数放回历史，逐 bar 模拟"如果当时严格按规则执行会怎样"**。

整个引擎（`backtest/engine.py`）的核心是一条会计恒等式：

```
策略收益[t] = 仓位[t-1] × 资产收益[t] − 换手[t] × 成本
```

逐项拆开：

**① `仓位[t-1]`——为什么是昨天的仓位？**
这一个 `shift(1)` 是整个回测正确性的命脉。你在 t 日收盘后根据 t 日数据做出的决策，最早只能吃到 t+1 日的涨跌。如果写成 `仓位[t] × 收益[t]`，策略就在用今天的信息吃今天的收益——这叫**前视偏差（look-ahead bias）**，是回测虚高的第一大来源。一个被前视污染的回测可以让任何垃圾策略年化 100%。

**② `换手 × 成本`——为什么必须扣？**
换手 = |今日仓位 − 昨日仓位|，每次进出场都按单边成本（默认 10bps = 0.1%，涵盖佣金+滑点）扣减。很多"看起来很灵"的高频信号（比如裸 MACD 金叉死叉）在扣除成本后直接由盈转亏——**信号频率与成本是天敌**，这是回测教给新手的第一课。我特意把 `strat_macd` 留在内置策略里，就是让你亲眼看到这件事。

**③ 输出两条曲线，回答两个问题：**

- **收益问题**：策略净值 vs 买入持有净值。买入持有是所有主动策略的及格线——你做了那么多操作，赢过"什么都不做"了吗？
- **风险问题**：同样的终点，路径可以天差地别。指标体系（`metrics.py`）：

| 指标 | 回答的问题 |
|---|---|
| CAGR | 这条曲线相当于每年复利多少 |
| 夏普比率 | 每承担 1 单位波动换来多少收益（个股策略 >0.8 不错，**>1.5 先怀疑代码有 bug**） |
| 最大回撤 | 从最高点最多跌掉多少——决定你拿不拿得住 |
| 最长水下期 | 两次创新高之间最久隔多少天——心理上比回撤深度更难熬 |
| 日胜率 | 注意：趋势策略胜率常 <50% 但单次赢得大，胜率必须配合盈亏比看 |
| 持仓暴露 | 平均仓位——sma200 策略暴露 ~70% 意味着它有 30% 的时间在场外躲风险 |

## 三、具体怎么执行

```bash
# 单策略回测：AAPL 五年，200日线过滤，成本 10bps
finloop backtest AAPL --strategy sma200

# 全部内置策略横向对比
finloop backtest SPY --strategy all --period 5y

# 调高成本做敏感性测试（成本翻倍后还赚钱的策略才皮实）
finloop backtest QQQ --strategy momentum --cost 20
```

写自己的策略只需三步：

```python
# 1. 在 backtest/strategy.py 写一个函数：enrich后的df → 仓位序列
def strat_my_idea(df):
    return ((df["close"] > df["sma200"]) & (df["rsi14"] < 60)).astype(float)

# 2. 注册进 STRATEGIES 字典
STRATEGIES["my_idea"] = strat_my_idea

# 3. 跑
# finloop backtest AAPL --strategy my_idea
```

## 四、事件研究：验证信号，而不是验证策略

回测检验的是"完整的进出场规则"，但有时你想问的是更基础的问题：
**"黄金交叉这个信号本身到底有没有信息量？"**——这用事件研究（event study）回答：

```
1. 扫描历史上该信号的每次发生时点
2. 计算每次发生后 5/20/60 天的前向收益
3. 与基线比较：随便挑一天的同周期前向收益是多少？
4. 信号后收益 − 基线 = 超额；超额/标准误 = t 统计量
```

`finloop eventstudy AAPL` 会输出每类信号的：发生次数、信号后均值收益、基线、超额、命中率、t 值。**|t|>2 约对应 95% 置信"不是碰巧"**。

这直接回答了"信号星级凭什么"——跑完事件研究，星级就从经验断言变成了你自己数据上的统计量。

## 五、回测的四大陷阱（结果好≠策略好）

**1. 前视偏差**：用了当时不可能知道的信息。除了忘记 shift，隐蔽形态包括：用"当日最高价买入当日最低价"、用复权价计算历史触发价位、用今天的指数成分股名单回测十年前。

**2. 幸存者偏差**：你回测的 AAPL/NVDA 是活到今天的赢家。2000 年的投资者面对的菜单里满是后来归零的公司。**单票回测的漂亮结果，一半归功于"你已经知道它活下来了"**。缓解：多票回测（包括表现平庸的）、用指数 ETF、对结论自动打折。

**3. 过拟合（最危险）**：参数调到 197 日线比 200 日线年化高 2%？那不是发现，是把历史的噪声背下来了。识别特征：参数微调结果剧变、规则越加越多、样本外立刻失效。防御：
   - **参数敏感性**：好策略在参数邻域内表现平滑（150/200/250 日线都应大致可用）；
   - **样本外验证**：只用前 70% 数据开发，最后 30% 只许碰一次；
   - **走前验证（walk-forward）**：滚动地"用过去 3 年定参数 → 下 1 年验证"，是最接近实盘的检验；
   - **少调参**：本框架内置策略全部用文献默认参数、零优化，宁要诚实的平庸也不要虚假的卓越。

**4. 多重假设检验**：同时检验 15 种信号，按 5% 显著水平，纯随机也会有约 1 种"显著"。你看到的"最佳策略"，部分是运气的最大值统计量。防御：跨多只票、多时段稳定显著的信号才可信；对"试了多少次才找到它"保持诚实。

## 六、正确的心智模型

回测**不能**告诉你策略未来会赚多少——市场状态会迁移，历史分布不承诺延续。

回测**能**做到的是证伪与排雷：
- 淘汰扣除成本后连历史都跑不赢的想法（绝大多数想法死在这一步，这是它最大的价值）；
- 暴露风险形态：最大回撤 35% 的策略，你实盘扛不扛得住要先想清楚；
- 校准预期：知道策略在震荡年份会钝刀割肉，实盘遇到时才不会在最糟的时刻弃用。

一句话：**回测是过滤器，不是预言机。它的工作是杀死坏策略，而不是保证好策略。**
