# 技术指标详解

> 配合 `finloop explain <指标名>` 使用，本文是更完整的书面版。
> 所有指标实现位于 `src/finloop/indicators/`，纯 pandas，可对照源码学习公式。

## 指标的四个家族

理解指标的第一步是分类——每个家族回答一个不同的问题：

| 家族 | 回答的问题 | 本框架实现 |
|------|-----------|-----------|
| 趋势 | 价格朝哪个方向走？ | SMA、EMA、MACD |
| 趋势强度 | 趋势有多坚决？（不分方向） | ADX (+DI/-DI) |
| 动量 | 涨跌速度多快？是否极端？ | RSI、Stochastic、ROC |
| 波动率 | 市场多躁动？偏离均值多远？ | 布林带、ATR |
| 量能 | 价格变化有没有资金支持？ | OBV、VWAP、量比 |

**元规则：不要叠加同家族指标。** RSI + KD + 威廉指标本质是同一个信息源的三次重复，
互相"确认"毫无意义。有效的组合是跨家族的，例如：趋势（200日线）+ 动量（RSI 区间）+ 量能（OBV 背离）。

## 趋势类

### SMA 简单移动平均线

**公式**：`SMA(N) = 最近 N 根收盘价之和 / N`

美股三条关键均线：

- **20 日**（≈1 个月）：短期趋势。强势股回调常在此获得支撑。
- **50 日**（≈1 个季度）：中期趋势，机构最常引用。"回踩 50 日线"是华尔街语境里最高频的加仓位置。
- **200 日**（≈1 年）：长线牛熊分界。大量统计显示，只在价格位于 200 日线上方时持有股指，
  能避开历史上大部分深度熊市（代价是震荡期的反复进出）。

**多头排列**（20>50>200，且都向上）说明短中长期资金方向一致，是趋势最健康的形态。

**误区**：均线是滞后指标。它确认趋势，不预测拐点；震荡市里均线交叉会反复打脸（whipsaw）。

### EMA 指数移动平均线

对近期价格加权更高（权重 α=2/(N+1) 指数衰减），反应快于 SMA。
日内交易常用 **9/21 EMA** 组合刻画日内趋势节奏。快的代价是噪声更多。

### MACD

**公式**：
```
MACD 线 = EMA(12) − EMA(26)     # 快慢均线差 → 中期动能
信号线  = MACD 线的 EMA(9)       # 平滑触发线
柱状图  = MACD 线 − 信号线        # 动能的加速度
```

三个层次的读法，可靠度递增的关键在**零轴位置**：

1. **金叉/死叉**：MACD 上/下穿信号线。零轴上方的金叉（上升趋势中的回调结束）远比零轴下方的金叉（下跌中的反弹）可靠。
2. **柱体拐点**：柱体从放大转收缩，往往领先金叉死叉 2-5 根 K 线，是最早的动量变化证据——本框架的动量切换检测大量使用这一点。
3. **背离**：价格新高而 MACD 高点降低 = 顶背离（动能衰竭预警）；反之底背离。背离是"减仓信号"而非"反向开仓信号"。

### ADX 平均趋向指数

ADX 是**策略选择器**，这是它最重要的用法：

| ADX 读数 | 市场状态 | 该用的策略 |
|---------|---------|-----------|
| < 20 | 无趋势（震荡） | 均值回归：低吸高抛、布林带边界 |
| 20–25 | 灰色地带 | 减仓观望，等待方向 |
| 25–40 | 有效趋势 | 趋势跟随：顺势加仓、移动止盈 |
| > 40 | 极强趋势 | 严禁逆势；趋势衰竭前不猜顶底 |

方向不看 ADX 本身，看 **+DI 与 -DI 谁在上方**。
ADX 高位回落 ≠ 反转，只代表趋势强度减弱（可能横盘休整后继续）。

## 动量类

### RSI 相对强弱指数

**公式**：`RSI = 100 − 100/(1+RS)`，RS = N 日平均涨幅/平均跌幅（Wilder 平滑，N=14）。

比 70/30 超买超卖更深一层的用法是**区间迁移**：

- 牛市中 RSI 通常运行在 **40–90**，回调到 40–50 就是支撑（而不是等 30）；
- 熊市中通常运行在 **10–60**，反弹到 55–60 就是阻力。
- 当 RSI 的运行区间从一种形态迁移到另一种，往往意味着趋势级别的转换——这比任何单次读数都重要。

**最大误区**：强趋势中 RSI 长期钝化在超买区，机械地"RSI>70 就卖"会让你在每只大牛股上提前下车并反复被打脸。先用 ADX 判断市场状态，再决定 RSI 用法。

### Stochastic 随机指标（KD）

刻画收盘价在近 N 日高低区间中的位置。比 RSI 更敏感、噪声更大，
适合**震荡市**的高抛低吸节奏（20 下方 K 上穿 D 买、80 上方 K 下穿 D 卖），趋势市中只作次级确认。

### ROC 变动率

`ROC(N) = N 日收益率`。学术金融中著名的**动量效应**（过去 3–12 个月的强势股在未来继续跑赢）
正是建立在这个最朴素的量上。ROC 穿越零轴是"动量方向切换"最直接的定义。

## 波动率类

### 布林带

中轨 SMA(20)，上下轨 ±2σ。两个衍生量比轨道本身更有用：

- **%B**：价格在带中的位置（>1 突破上轨，<0 跌破下轨）；
- **带宽**：(上轨−下轨)/中轨，波动率的直接读数。

核心洞察是**波动率循环**：极度收缩（挤压，squeeze）之后往往爆发趋势行情。
本框架的"挤压放量突破"信号 = 带宽处于近半年最低 15% 分位 + 放量（量比>1.5）突破轨道。

强趋势中的 **band walking**（价格贴着上轨爬升）是健康强势的表现，不是卖出理由——这是布林带最常被误用的地方。

### ATR 平均真实波幅

衡量"这只票一天正常动多少"（含跳空）。它不指示方向，是**风险管理指标**：

- 止损：入场价 ∓ 2×ATR，让止损适配标的的呼吸幅度，而不是统一拍一个百分比；
- 仓位：固定单笔风险额时，`仓位 = 风险额 / (2×ATR)`——波动大的票自动小仓位。

## 量能类

### OBV 能量潮

上涨日累加成交量、下跌日累减。绝对值无意义，看**形态与背离**：
价格新高 + OBV 不新高 = 上涨没有资金支持（顶背离）。"量在价先"的经典实现。

### VWAP 成交量加权均价

当日全部成交的真实平均成本。机构执行算法大量锚定 VWAP，使它成为日内最重要的多空分界线与磁力线：

- 价格在 VWAP 上方 → 日内买方占优，回踩 VWAP 不破是顺势买点；
- 偏离 VWAP 过远 → 有回归引力。

**注意**：VWAP 只对单个交易日的日内数据有意义，必须每日重置累计（本框架 `enrich(df, intraday=True)` 已按日分组）。

### 量比

当日量 / 20 日均量。>2 显著放量、<0.5 明显缩量。
价格信号 + 放量 = 可信度加成；放量下跌比缩量下跌危险得多。
