# AI 产业链深度地图（细粒度版）

> 调研快照：2026-06（基于多 agent 网络调研，来源：公司财报/IR、TrendForce、
> Counterpoint、LightCounting、Wood Mackenzie、TECHCET、DigiTimes 等行业渠道）。
> 数据会过时——每季财报后应重新验证关键数字。
> 瓶颈分：1-5，5 = 单一来源卡脖子。⛔ = 私有/已退市，不可直接投资但必须理解。
> 可交易代码均为 yfinance 兼容格式，已收录进 `config/universe_ai.yaml`。

## 总览：钱从哪里流过

```
推理/训练需求 → 云厂 capex → GPU/ASIC (NVDA/AMD/AVGO)
  ├─① 先进封装 CoWoS (TSM) ─ ABF载板 ─ ABF膜 ─ T-glass玻璃布   ← 越往右越垄断
  ├─② HBM (SK海力士/MU/三星) ─ TC键合机 ─ 硅片 ─ 石英坩埚 ─ 高纯石英矿
  ├─③ 光互联 ─ 光模块 ─ EML激光器 ─ InP衬底
  ├─④ 整机电源散热 ─ 冷板/CDU/UQD ─ VRM ─ 电源架
  └─⑤ 数据中心电力 ─ 变压器 ─ 电气钢 ─ 发电/核电 ─ 电气施工
```

**2026 年中已验证的总闸门数据**：TSMC CoWoS 产能 35k 片/月（2024 末）→ 130-150k
片/月（2026 末），预订排到 18 个月后，NVDA 锁定 2026 年 60%+ 产能（约 60-85 万片/年），
Broadcom 24 万片（Meta/Google ASIC）。缓解最早 2027。

```
 (TSM)    (TSM/ASE/AMKR)    (四寡头)    (Ajinomoto)      (Nittobo)
```

| 封装检测 | Camtek(CAMT)、Onto(ONTO) | 3 | Camtek 在手订单 $260M+（HBM 检测），2026H2 指引 +25% |

**该链"需求>>估值"研究焦点**：垄断材料商（Ajinomoto、Nittobo）的提价是利润率的
直接杠杆，但都藏在大集团里（Ajinomoto 电子材料只占收入 6%——纯度问题）；载板四寡头
是供需缺口的全弹性敞口；设备商看"谁拿了哪家 HBM 厂的下一代机型"。

## 使用方式

1. **筛选**：`finloop screen --tier upstream`（universe 已更新为本地图的可交易标的）
2. **验证需求**：每季对照本文档"需求证据"列——提价、交期、backlog、book-to-bill 是否仍在恶化（对上游而言恶化=利好）
3. **验证估值**：screener 的 gap 排名 + 人工核对 forward PE 相对增速
4. **跟踪闸门**：四家云厂 capex 指引（总闸门）、TSMC CoWoS 月产能（封装闸门）、
   Wood Mackenzie 变压器交期（电力闸门）、LightCounting 模块出货（光闸门）

## 本地图的已知局限（诚实声明）

- 数据是 2026-06 的快照，市占率/交期/价格在快速变化，引用前先重验；
- 多数细分数据来自行业媒体转引（TrendForce/DigiTimes 等），非一手财报的数字应降权处理；
- 日台韩标的的 yfinance 基本面字段覆盖率低，screener 的估值打分对它们可能缺数据（coverage 列会显示）；
- A 股标的（300308 等）有外资准入与流动性约束，列入是为了产业链完整性；
- ⛔私有节点（Spruce Pine 石英、Stäubli、Shinko、JSR）无法投资，但它们出事会传导到整条链——是风险监控对象。
