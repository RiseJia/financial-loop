## 一、把问题翻译成会计恒等式

"数据中心要建多少"听起来是产业问题，其实是一道除法题：

```
数据中心功率需求(GW) = Token 月需求量 × 单 token 计算成本 ÷ 算力效率(token/秒/MW)
```

三个变量，三股力量：

| 变量 | 方向 | 当前数据 |
|---|---|---|
| Token 需求量 | ↑↑ 推高需求 | Google 单家：9.7T/月(2024)→480T(2025)→3,200T(2026-05)，**年化 7 倍**（前一年 50 倍） |
| 单 token 计算成本 | ↑ 温和推高 | 推理模型（思维链）让单次回答消耗更多 token；模型变大单 token 算力也涨 |
| 算力效率 | ↓↓ 压低需求 | Hopper→Blackwell：~10x token/MW；Blackwell→Rubin：宣称再 ~10x/瓦。**每两年约一个数量级** |

**全部争论的本质**：分子（需求）跑得过分母（效率）吗？目前的实测答案是
"远远跑得过"——7x 需求 vs ~3.2x/年的效率（10x/2年开方），净缺口每年还在
扩大约 2 倍。这就是为什么效率提升了 10 倍、token 单价跌了 1000 倍，
数据中心反而越建越多（Jevons 效应的算术本质）。

> 〖思维工具 1〗**任何"X 还能持续多久"的问题，都改写成两条增长曲线的
> 赛跑**。单看需求会永远乐观，单看效率/供给会永远悲观，答案只存在于
> 两者的相对速度里。这个工具适用于一切产能周期：航运、油气、存储芯片。

## 二、需求端：token 从哪里来，agentic 为什么是关键变量

### 2.1 实测数据

- **Google 口径**：3.2 quadrillion token/月（2026-05，I/O 大会），YoY 7x。
  375 个云客户年消耗超 1 万亿 token。⚠️ 口径警告：这是**自报、未审计**的
  指标，且包含搜索 AI Overview 这类"廉价 token"（被动生成、单 token
  收入极低）——数字真实但商业含金量分层。
- **Agentic 乘数**（本章核心）：Gartner 口径 agent 任务耗 token 是聊天的
  **5-30 倍**；学术实测：5 步循环 3.2x、50 步 >30x、200 步（自主调试
  会话）**>100x**。机制：agent 每一步都要把累积的全部上下文重新喂给
  模型——第 20 步时你在为同一段上下文付第 20 次钱。
- **微观印证**：重度 agentic 开发者月消耗 $400-1,500，极端案例数天
  $4,000+；企业开通 coding agent 后 90 天内 AI 账单常成为工程部门
  第二大开支。
- **需求质量**：推理（而非训练）已是 Blackwell 算力时长的边际买家；
  agentic 负载绑定 SLA、**价格弹性低**（训练可以暂停，给用户跑到一半的
  agent 不能）。OpenAI/Anthropic 2026 年 3 月双双上调推理算力预订。

### 2.2 怎么理解"7 倍增速"的构成

把 token 需求拆成 `用户数 × 人均任务数 × 单任务 token 数`：
- 用户数：chatbot 渗透接近饱和（Google AI 模式一年 10 亿用户）——
  这个引擎在减速；
- 单任务 token 数：**chatbot→agentic 的切换就是 5-100 倍的乘数**——
  这个引擎刚点火（agentic 渗透率仍是个位数百分比量级）；
- 含义：未来 2-3 年 token 增速的主引擎从"更多人用"换成"同样的人用
  得深 100 倍"。判断 token 增速能否维持 >3x，**等价于判断 agentic
  渗透率曲线的斜率**——这是整个研判中最该盯的单一变量。

> 〖思维工具 2〗**对一切自报指标先问口径**：谁报的、含不含低价值成分、
> 有没有独立验证。3.2 quadrillion 是真数字，但其中搜索附带 token 和
> 付费 API token 的商业价值差几个数量级。增速可以引用，构成必须拆分。

## 三、效率端：最容易被忽略的反作用力

- Hopper→Blackwell：MoE 推理吞吐/MW 提升 ~10x；配合软件优化，
  GB300 对 DeepSeek-R1 实测达 50x 吞吐/MW、token 成本 -35x
  （SemiAnalysis InferenceMAX 独立基准——注意 50x 是特定模型+软件
  栈的最佳情形，保守用 10x）。
- Blackwell→Rubin：NVDA 宣称 NVL72 推理吞吐/瓦 ~10x（厂商口径，
  打折后估 3-5x）。
- 长周期：NVDA 称六代产品推理吞吐/MW 提升 100 万倍——营销数字，
  但量级方向正确：**效率年化 ~3x 是个稳健的工作假设**。

效率的双刃性（务必想透）：
- 对**数据中心总需求**：效率是减项（同样 token 用更少 GW）；
- 对**芯片厂商**：效率是卖点不是威胁（旧卡被效率淘汰 = 替换需求）；
- 对**token 应用方**：效率是燃料（成本降 → 可行用例增 → 需求再涨）。
同一个 10x，在链条三个位置是三种含义——分析任何技术进步新闻时，
先问"对我正在研究的那一层是加项还是减项"。

> 〖思维工具 3〗**增速放缓 ≠ 下降，但对成长股是同等杀伤**。GW 需求
> 只要增速归零（哪怕绝对值在历史最高位），上游供应商的"成长股估值
> 框架"就会切换成"周期股估值框架"，估值倍数先于业绩崩。盯二阶导，
> 不要等一阶导转负。

## 四、合成：要建多少，建到什么时候

### 4.1 需求侧外推（机构口径）

- McKinsey 中性情景：全球数据中心需求 2030 年 **171-219 GW**（其中
  AI 工作负载 156 GW），AI-ready 容量需求 CAGR 33%（2023-30）；
  对应投资 **$5.2 万亿**（仅 AI）至 $6.7 万亿（合计）。
- 作为校准：四大云厂 2026 年 capex $660-725B —— 即使按 McKinsey 的
  万亿级路径，当前的开支节奏也已经在"中性偏快"的轨道上。

### 4.2 供给侧硬承诺（订单簿，比预测可靠的部分）

| 证据 | 数字 | 隐含可见度 |
|---|---|---|
| NVDA Blackwell+Rubin 订单 | **$1 万亿 through 2027** | 芯片需求锁到 2027 末 |
| Blackwell 售罄 | 至 2027 | 同上 |
| Stargate（OpenAI/Oracle/软银） | 10GW/$500B，已落地近 7GW/$400B | 完工线 2029 |
| Anthropic TPU | 2026 上线 1GW+，2027 再 5GW+ | 2027 |
| CoWoS/HBM/变压器排单 | 18 个月~5 年 | 2027-2030 |

**结论：2027 年末之前的数据中心建设是"已付定金"级别的确定性**——
取消它比继续建它更贵。真正的开放问题是 2028 起的新增订单。

### 4.3 摩擦项：建得出来吗

- **30-50% 的 2026 规划产能将因电网互联与施工瓶颈滑到 2028**——
  注意这对上游是**利好**（需求被展期而非消失，紧缺被拉长）；
- PJM（美最大电网区）容量缺口在 2027/28 拍卖扩大到 6.5GW+，容量价格
  一年涨 9.3 倍；居民电价暴涨已引发监管反弹（联邦监察建议科技公司
  自建电力）——**电力的政治经济学是 2027+ 最被低估的尾部风险**；
- 部分分析师已警告 2026H2-2027 局部环节（电力与冷却设备）过剩——
  与我们 08 篇"供给海啸 ETA 2027-28"吻合。

> 〖思维工具 4〗**把可见度分层：订单簿可见度 vs 叙事可见度**。
> "$1 万亿订单 through 2027"和"McKinsey 预测 2030 年 219GW"是两种
> 完全不同硬度的证据——前者违约有真金白银的代价，后者是模型外推。
> 仓位的久期不应超过订单簿可见度太多。

### 4.4 三情景研判（核心交付）

| 情景 | 机制 | GW 需求拐点 | 概率感* |
|---|---|---|---|
| **基准** | agentic 渗透稳步爬升，token 增速 7x→4-5x 缓降；效率 ~3x/年 | 增速 2028-29 放缓，2030 前后进入平台期（替换需求接棒） | ~50% |
| **乐观** | agentic 全面爆发（每个知识工作者背后一个 agent 集群）+ 视频/机器人新形态接力 | 2030 年代仍在扩张（McKinsey 高情景 300GW+） | ~25% |
| **悲观** | 企业 agentic ROI 证伪，token 增速 2027 滑破 3x（跌破效率线） | **2027-28 即见顶**，恰与供给海啸重叠 → 上游双杀 | ~25% |

\* 概率感是主观贝叶斯起点，不是计算结果——它存在的意义是被后续证据更新。

注意悲观情景的结构：它不需要"AI 失败"，只需要 agentic 渗透曲线比预期
平缓两年。**而 2027-28 恰好是全产业链扩产落地的时间**——需求增速失速
与供给海啸同时到达，就是 2000 年光纤的精确复刻。这是为什么第五章的
监控面板里 token 增速指标的权重最高。

## 六、你的两个支线猜想：评估

**猜想一：小区级/边缘算力集群**。方向有依据——推理对延迟敏感的部分
（实时交互、隐私场景）有下沉动力，且分散部署缓解电网瓶颈。但当前
经济学反对大规模下沉：大集群的 batch 推理效率和利用率远高于分散小
集群，token 单位成本差数倍；目前"边缘"主要发生在端侧芯片（手机/PC
NPU），而不是小区机房。**判定：远期期权，挂 frontier 跟踪两个先行
指标（电信运营商边缘机房改造订单、推理延迟敏感应用的收入占比），
当前不改变上游主线。**

**猜想二：token 消耗的新形态**。这个猜想几乎必然正确，且已在发生：
视频生成的 token 密度是文本的百倍以上（Veo/Sora 类产品放量）、
机器人/物理 AI（仿真训练 token 是无底洞）、AI for Science。它们是
**乐观情景的弹药库**——每个新形态都是 token 需求的免费期权。但纪律：
期权不计入基本盘估值，兑现一个算一个。

> 〖思维工具 6〗**把"未来可能性"区分为基本盘与期权**。基本盘
> （chatbot+agentic 的 token 增长）支撑当前判断；期权（边缘/视频/
> 机器人）只影响情景概率的分布，不进当前的需求模型。把期权当基本盘
> 定价，是每轮泡沫顶部的共同特征。
