# 07 下游应用与变现：token 成本降 1000 倍后，钱在哪一层沉淀

## 本层回答的问题

AI 最终靠什么赚钱？成本暴跌是利好还是利空？应用层的护城河长什么样？
——以及对你最重要的：下游的健康度如何反推上游的可持续性。

## 核心数字（2026-06 快照）

- **Token 成本坍缩**：GPT-4 级别推理成本从 2022 末 ~$20/百万 token 降至
  2026 初 **~$0.40——三年 1000 倍**，且仍以每年 9-900 倍的速度下降；
- **训练→推理的重心迁移**：推理已占 AI 算力开支 55%+，预计走向 70-80%；
  模型生命周期总算力中推理占 80-90%。**这是产业结构性转折：训练是一次性
  资本开支，推理是随用量增长的经常性开支**；
- **成本悖论（Jevons 效应）**：单位 token 价格暴跌，但企业 AI 总账单在暴涨
  ——agent 工作流让单次任务消耗的 token 量增长快于单价下跌。这正是
  "成本降 1000 倍反而利好算力需求"的机制。

## 变现模式图谱

| 模式 | 代表 | 经济学特征 |
|------|------|-----------|
| API 卖 token | OpenAI/Anthropic/Google | 直面成本坍缩，毛利率取决于推理效率与品牌溢价；价格战常态化 |
| 订阅（Copilot/ChatGPT Plus） | MSFT/OpenAI | 最像传统 SaaS，单用户算力成本是毛利率的暗雷 |
| 嵌入式增强（AI 功能抬 ARPU） | ADBE/NOW/CRM | 不单独收费也能提价/防流失——财务上最稳的变现 |
| 广告/推荐增效 | META/GOOGL/APP | AI 提升现有引擎效率，**当前已被验证的最大规模变现**（META 广告定价的提升是 AI 收入，只是不叫这个名字） |
| 平台/咨询交付 | PLTR | 把模型变成企业工作流，吃实施与平台费 |

**关键判断**：目前对上游 capex 的覆盖度，"已验证的 AI 收入"（广告增效 +
订阅 + API ≈ 低数千亿美元量级）仍显著小于年投入（$725B capex + 运营成本）。
**缺口靠"预期中的未来收入"支撑——这就是本轮周期的核心赌注**（08篇展开）。

## 应用层的护城河问题

成本坍缩对应用层是双刃剑：你的成本下降，竞品的成本同样下降——**模型能力
本身不构成应用层护城河**（开源模型 + API 让能力人人可得）。可持续的壁垒
回到经典清单：
1. **专有数据与工作流嵌入**（NOW/CRM 类：换掉它要重构业务流程）；
2. **分发网络**（MSFT 把 Copilot 塞进 Office 的渠道力）；
3. **网络效应**（用户越多模型反馈越好的闭环——少数产品真正具备）。

"AI 应用股"的筛选问题不是"用没用 AI"，而是"AI 是否加深了它原有的护城河"。
反例同样重要：AI 让代码生成、客服、设计的边际成本趋零——**被 AI 降低
进入门槛的软件公司，护城河在变浅**（这是下游的空头猎场）。

## 下游健康度 → 上游可持续性的反推链

这是本篇对你的主线最重要的部分。上游的一切（01-05篇）最终由下游买单：

```
下游 AI 收入增速  ──支撑──▶ 中游 capex 增速 ──决定──▶ 上游订单/提价
     │                            │
     ▼ 若收入增速 < 算力成本沉没速度
  capex 退坡 ──▶ 鞭子效应放大 ──▶ 上游提价逻辑反转（先于收入下滑）
```

**领先指标排序**（越靠前越早变色）：
1. token 消耗量增速（各 API 平台口径）——需求的最上游读数；
2. 企业 AI 预算调查（CIO survey）与 AI 应用公司的 NDR（净收入留存率）；
3. 订阅产品的提价能力与续费率（Copilot 渗透率是单一最佳样本）；
4. 模型公司融资环境（一级市场降温 = 算力承诺缩水的前奏）。

## 关键跟踪指标

| 指标 | 频率 | 看什么 |
|---|---|---|
| 巨头财报中 AI 收入披露（Azure AI、Copilot 数） | 季度 | 已验证收入的增速 |
| API 定价变动 | 新闻流 | 价格战烈度 |
| Agent 类产品的 token 用量数据 | 新闻流 | Jevons 效应的兑现度 |
| AI 应用公司毛利率 | 季度 | 推理成本是否吞噬 SaaS 利润率 |

## 投资视角

- 你的主线在上游，下游的角色是**仪表盘而非猎场**：每季度核对"已验证 AI
  收入"对 capex 的覆盖度是否在改善——改善则上游论点续期，恶化则触发
  深度报告里的证伪流程；
- 若要配置下游，选"AI 加深原有护城河"型（广告引擎/工作流嵌入），
  回避"AI 降低其进入门槛"型；
- 工具：`finloop analyze META`（已验证变现的代表）、
  `finloop screen --tier downstream`。
