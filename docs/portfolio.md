# 个人投资使用手册：从研究框架到实际操作

> 本文回答一个问题：**这套东西怎么用于真金白银，以及在什么条件下才可以**。
> 工具：`finloop portfolio`（组合体检）、`finloop size`（仓位计算）。
> 持仓文件：`config/portfolio.local.yaml`（gitignored，模板见 portfolio.yaml）。

## 一、上线前检查清单（Going-live checklist）

打勾之前不要投入真钱。逐项核对：

- [ ] **重跑验证已完成**：v0.3.0 审计修复动摇了两个既往结论（"双高不存在"、
      "没策略跑赢买入持有"），必须在有网络的环境重跑
      `finloop screen --tier upstream` 与 `finloop research --tier upstream`
      并阅读对比结论——在旧的、有缺陷的榜单上选的标的不能直接用；
- [ ] **纸面组合先跑一个月**：把想买的仓位填进 portfolio.local.yaml（真实价格、
      假想股数），每周跑 `finloop portfolio` 和日报，体验一遍纪律被触发的感觉
      （止损提示出现时你的真实心理反应，比任何回测都有信息量）；
- [ ] **单笔风险与上限已按自己的承受力校准**：默认值（单笔 0.5%、单标的 20%、
      子链 40%、现金下限 5%）是文献通用值——如果你无法接受账户单日 -3%，
      把 risk_per_trade 调小；
- [ ] **读过 docs/chain/08 的周期面板**并理解当前位置（2026 年中=扩张中后段，
      提价潮+扩产密度高峰+全面定价，本身就是仓位水位要保守的证据）；
- [ ] **知道这套工具不做什么**（见第四节）。

## 二、日常操作节奏（把 workflow.md 的生命周期变成日历）

| 频率 | 动作 | 命令/文件 |
|---|---|---|
| 每日（5 分钟） | 看日报：持仓信号、大盘 regime、触发器异动 | `finloop report`（cron 已自动） |
| 每周（15 分钟） | 组合体检：权重漂移/止损距离/集中度 | `finloop portfolio` |
| 建仓前（每次） | ①analyze 全景 → ②size 定股数与止损 → ③portfolio 预演加仓后集中度 | `finloop analyze/size/portfolio` |
| 每财报季（半天） | 调研循环：loop-status 清单 → 触发器签到 → 深挖名单复核 → screen 重跑 | `finloop loop-status/screen` |
| 每年（1 次） | Google I/O 后刷新 token 增速锚（悲观情景启动线） | research_state 全局触发器 |

**建仓流程固定为四步，不跳步**：
1. 标的必须来自深挖名单（研究在前）且"值得买的条件"已满足；
2. `finloop size X` 拿股数和止损价——**止损价写进 portfolio.local.yaml 才算存在**；
3. 手动预演：把假想仓位加进 .local 文件跑 `finloop portfolio`，看会不会触发
   集中度警告——会的话减量；
4. 下单后立刻把真实成交写回 .local 文件（含 node 字段关联论点节点——
   这样论点触发器变黄时体检会点名提醒你）。

## 三、纪律的技术实现（哪个规则在哪里被强制）

| 纪律 | 来源 | 代码强制点 |
|---|---|---|
| 单笔风险 ≤0.5% | docs/intraday.md | `finloop size` 的股数计算 |
| 止损 = 2×ATR | docs/indicators.md | `size` 输出；`portfolio` 检测跌破并 🔴 |
| 单标的 ≤20% | docs/long_term.md | `size` 的上限约束 + `portfolio` 警告 |
| 单子链 ≤40% | docs/long_term.md | `portfolio` 按 universe 子链聚合警告 |
| 现金下限 5% | docs/long_term.md | `portfolio` 警告 |
| 论点死亡即离场 | research_loop | 持仓 node 关联触发器，黄灯时体检点名 |
| 周期面板降档 | docs/chain/08 | 人工（面板≥3信号转向→手动降水位）——**未自动化，这是有意的**：战略判断不交给规则引擎 |

## 四、这套工具不做什么（与你必须自己做什么）

**不做**：
- 不自动交易、不发买卖指令——所有输出是决策支持，下单的手是你的；
- 不预测涨跌——回测是过滤器不是预言机（docs/backtesting.md 第六节）；
- 不替你读财报——screener 是漏斗第一层，深挖名单的"核实问题"必须人工做
  （本框架历史上三次重大修正——Nittobo 假便宜、KYEC 假恶化、SUMCO 前提错
  10 倍——全部靠人工核验抓出，没有一次是自动的）；
- 不保证数据正确——免费数据源有静默错误前科，预警列干净 ≠ 数据正确。

**你必须自己做**：执行止损（工具只会提示）、季度触发器签到（15 分钟）、
每次买入前走完四步流程、以及最难的一条——**在面板亮灯时真的降仓位**。

## 五、已知限制（诚实清单，投入真钱前再读一遍）

1. **信号未经样本外验证**：拐点/动量信号的星级基于文献与全样本事件研究，
   无 walk-forward——把它们当"关注提示"而非"交易指令"；
2. **回测的幸存者偏差**：universe 是事后已知的 AI 赢家，回测结论向上偏；
3. **非美标的数据薄弱**：日股无备源、韩股备源被网络策略挡、基本面字段
   覆盖率低——台/日/韩持仓的体检质量低于美股；
4. **估值数据快照无 point-in-time**：跨期比较用 reports/research/data/ 快照；
5. **周期位置风险**：本框架诞生于 AI 扩张中后段（2026 年中），全部调研
   证据都带着这个时代印记——悲观情景（token 增速失速 + 2027-28 供给海啸）
   的对冲预案见 round5 报告 B 节，别等亮灯才第一次读它。
