# AI 产业链体系化教程（docs/chain）

> 目标：读完本系列，你能独立理解 AI 行业上下游每一层**为什么存在、谁说了算、
> 钱怎么赚、周期怎么转**——而不只是记住一堆公司名。
> 每篇统一结构：本层回答的问题 → 技术第一性原理 → 格局与玩家 → 经济学特征
> → 关键跟踪指标 → 投资视角。
> 数据快照：2026-06。结构性内容（原理/格局成因）长期有效，数字会过时。

## 阅读路径

```
                    ┌─ 01 算力芯片层（大脑）
                    ├─ 02 制造与封装层（怎么造出来）
 上游（供给侧） ────┼─ 03 存储层（记忆）
                    ├─ 04 互联网络层（神经）
                    └─ 05 整机电力散热层（身体与口粮）
 中游（运营侧） ──── 06 算力经济学（云厂为什么烧钱、怎么回本）
 下游（需求侧） ──── 07 应用与变现（钱最终从哪来）
 元框架        ──── 08 周期与历史（这一切什么时候结束、如何判断）
```

- **零基础**：按 01→08 顺序读，每篇 15 分钟；
- **只关心投资**：先读 08（周期框架），再读你关注的层，最后用
  [ai_supply_chain_map.md](../ai_supply_chain_map.md)（节点速查）和
  [深度报告](../../reports/research/2026-06-11_ai_upstream_deep_dive.md)（逐公司分析）；
- **配合工具**：每篇末尾"投资视角"对应 `finloop screen / analyze / signals` 的用法。

## 一张图：钱的流向（2026 快照）

```
 终端用户/企业付费（订阅/API/广告）            ← 07 下游
        │  ~$100B+ 量级的 AI 直接收入（仍远小于投入）
        ▼
 云厂与模型公司 capex：2026 年四大家 $660-725B（+77% YoY）← 06 中游
        │  其中 ~75% 流向 AI 基础设施
        ▼
 ┌──────┴───────────────────────────────┐
 │ GPU/ASIC ~40-50%        (01 算力层)  │
 │ 存储 HBM/DRAM ~10-15%   (03 存储层)  │
 │ 网络/光互联 ~10%        (04 互联层)  │
 │ 整机/电源/散热 ~10-15%  (05 物理层)  │
 │ 土地/建筑/电力 ~15-20%  (05/06)      │
 └──────┬───────────────────────────────┘
        ▼
 制造与封装（TSMC 及其设备/材料金字塔）        ← 02 制造层
        ▼
 材料与原料加工厂（ABF膜/T-glass/InP/电气钢…）  ← 各层最深处
```

**整个系列最重要的一句话**：每一层的投资价值 = 该层的**瓶颈程度 ×
定价权 × 离需求拐点的距离**。越往上游，公司越冷门、垄断越极端、
但对下游需求拐点的反应越滞后也越剧烈（鞭子效应：下游 capex 摆动 10%，
上游订单可以摆动 50%）。
