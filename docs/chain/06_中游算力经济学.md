# 06 中游算力经济学：$725B capex 的回本逻辑与脆弱点

## 本层回答的问题

云厂为什么敢一年烧七千亿美金？这笔账怎么算才能回本？整个上游繁荣的
地基到底有多稳？

## 核心数字（2026-06 快照）

- 四大云厂（MSFT/GOOGL/AMZN/META）2026 年 capex 合计 **$660-725B，
  同比 +77%**（2025 年 $410B）；加 Oracle 后五家 ~$690B+；
- 其中约 **75% 直接流向 AI 基础设施**（GPU/服务器/数据中心/设备）；
- 单家：AMZN ~$200B、MSFT ~$190B、GOOGL $175-185B、META $115-145B、ORCL ~$50B；
- 两家明确把上修归因于**内存与组件涨价**（MSFT 提到 $25B、META 上修 $10B）
  ——上游的提价（03篇）已经反噬中游的预算。

## 回本的算术（理解多空分歧的核心）

一块 GPU 的生命周期账：
```
收入 = 利用率 × 租金费率 × 服务年限
成本 = 采购价 + 电力/运营 + 资金成本
关键参数：
  折旧年限：会计上 5-6 年，但技术贬值更快——新一代芯片性能/瓦特翻倍时，
            旧卡租金费率坍塌（H100 租金已从峰值 $8/hr 跌至 $2 以下量级）
  利用率：训练负载饱和，推理负载波动——闲置一小时就是纯损失
```
**多头算法**：推理需求指数增长（07篇），token 量的增长跑赢单价下跌，
GPU 在 3 年内回本，剩余寿命全是利润；旧卡退役后转推理/内部负载继续榨取价值。
**空头算法**：折旧被系统性低估（5-6 年折旧 vs 2 年技术代际），当前云厂
利润率被"未来才体现的折旧"虚增；若 AI 收入增速放缓，巨额折旧将吞噬利润表。
**真相取决于一个变量**：AI 终端收入的增长是否持续跑赢算力成本的沉没速度。

## 三类玩家，三种风险

1. **超大规模云厂（MSFT/GOOGL/AMZN/META）**：用主业现金流（广告/电商/软件）
   补贴 AI 豪赌，资产负债表扛得住试错。风险是机会成本而非生存——但
   **2026 年起 capex 开始吃紧现金流**（CNBC：现金消耗显著），股东对回报
   证据的耐心是软约束；
2. **Neocloud（CRWV 等 GPU 租赁商）**：用债务杠杆买卡、租给云厂与模型公司。
   商业模式 = 利差生意（租金收益率 vs 融资成本 + 折旧），**对 GPU 残值
   与利用率假设极度敏感**——本质是"GPU 的银行"，周期下行时是整条链
   最脆弱的一环；
3. **模型公司（OpenAI/Anthropic 等，未上市）**：收入增长极快但烧钱更快，
   依赖持续融资。它们与云厂/芯片厂之间的**循环交易**（NVDA 投资 OpenAI、
   OpenAI 向 Oracle 承诺采购、Oracle 向 NVDA 买卡……）是本轮最受争议的
   结构——收入在链条内部循环计数，真实的外部需求被放大显示（08篇展开）。

## 自研 ASIC 的经济学（中游对上游的反噬）

云厂自研芯片的动机是纯算术：NVDA 毛利率 75%，意味着云厂每花 $4 买卡，
有 $3 是 NVDA 的毛利。自研芯片即使性能只有 70%，只要规模够大（自有负载
确定），TCO 就能省 30-50%。**ASIC 趋势不可逆，争的只是速度**——这决定了
上游分析里"NVDA 出货 × ASIC 出货"两个变量的权重此消彼长（AVGO/MRVL 受益，
NVDA 份额承压但市场总量扩大）。

## 关键跟踪指标

| 指标 | 频率 | 看什么 |
|---|---|---|
| 四大家 capex 指引 + 措辞 | 季度 | **整条产业链唯一的总闸门**。看"增速"而非绝对值 |
| 云业务收入增速 vs capex 增速 | 季度 | 剪刀差扩大 = 回本压力积累 |
| GPU 现货租金（H100/B200 $/hr） | 月度 | 算力供需的实时价格信号 |
| 云厂折旧政策变更 | 年报 | 延长折旧年限 = 利润压力的会计信号（红旗） |
| Neocloud 融资条款（利率/抵押结构） | 新闻流 | 链条最弱环节的资金链状态 |

## 投资视角

- 中游本身不是"需求>>估值"的猎场（巨头定价充分），但它是**上游一切论点的
  地基**——上游任何标的的研究笔记第一行都应该写：本标的的需求 = 中游 capex
  的函数，当前 capex 假设是 +77%；
- 对冲思路：持有上游多头的同时，中游的 capex 指引就是你的风控指标——
  它转弯时上游的鞭子效应（02篇）会放大数倍；
- 工具：`finloop analyze MSFT`、宏观日历跟财报季（四大家财报 = 上游持仓的
  季度大考）。
