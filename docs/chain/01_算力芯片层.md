# 01 算力芯片层：为什么 NVDA 拿走大部分利润

## 本层回答的问题

AI 的"算力"到底是什么？为什么一家公司能垄断它？这个垄断的裂缝在哪里？

## 技术第一性原理

**为什么是 GPU 而不是 CPU**：深度学习的本质是巨量的矩阵乘法——成千上万个
互不依赖的乘加运算。CPU 为"串行的复杂逻辑"设计（几十个强核心），GPU 为
"并行的简单运算"设计（上万个弱核心）。训练一个大模型 = 数万亿次矩阵乘法
× 数月，只有大规模并行架构在经济上可行。

**单芯片的三要素**（理解所有芯片新闻的钥匙）：
1. **算力（FLOPS）**：每秒浮点运算次数，由晶体管数量与频率决定 → 依赖先进制程（02篇）；
2. **显存带宽**：算得快没用，数据喂不进来就饿死 → 这就是 HBM 存在的原因（03篇）；
3. **互联带宽**：单芯片永远不够大，几万张卡如何像一张卡一样工作 → NVLink/网络（04篇）。

**真正的产品不是芯片，是系统**：NVDA 卖的单元已经从"一张卡"演进到
"一个机柜"（GB200/GB300 NVL72：72 颗 GPU 用 NVLink 连成一个统一计算域）再到
"一排机柜"（Rubin NVL144 → Kyber NVL576）。理解了这一点，才能理解为什么
电源、散热、铜缆这些"低科技"环节会爆单（05篇）。

## 格局与玩家

**NVDA 垄断的三层护城河**（按坚固程度排序）：
1. **CUDA 软件生态**（最硬）：二十年积累的开发工具链、库、人才习惯。
   迁移到别家芯片 = 重写/调优全部底层代码，对赶时间的 AI 公司是不可接受的成本；
2. **NVLink scale-up 互联**：把 72-576 颗 GPU 连成单一计算域的私有协议，
   竞品（UALink 联盟）落后一至两代；
3. **单芯片性能**：反而是最容易被追上的一层（AMD MI 系列纸面参数已接近）。

**挑战者两条路线**：
- **AMD（同路线竞争）**：MI300/325/350 系列，靠"纸面性价比 + 第二供应商"
  逻辑拿单。ROCm 软件生态是短板。本质是"NVDA 缺货时的泄压阀"，份额天花板
  受软件生态制约——除非推理市场（对软件生态依赖低于训练）足够大。
- **自研 ASIC（换路线竞争）**：Google TPU、Amazon Trainium、Meta MTIA、
  OpenAI 自研——云厂为**特定自有工作负载**定制芯片，绕开 CUDA（自己的模型
  自己优化）。设计伙伴是 **AVGO（份额最大）与 MRVL**。2026 年 AVGO 在 TSMC
  预订 24 万片 CoWoS（vs NVDA 80+ 万）——ASIC 阵营约为 NVDA 体量的 1/4-1/3 并在加速。
- **端侧/推理芯片**：QCOM、苹果自研等。推理向端侧迁移是远期变量。

**关键认知：训练与推理的分野正在重塑本层**。训练对 CUDA 依赖深、赢家通吃；
推理（已占算力开支 55%+，见07篇）对生态依赖浅、对单位 token 成本敏感——
**ASIC 与 AMD 的真正机会窗口在推理**。

## 经济学特征

- **毛利率**：NVDA 数据中心产品毛利率 ~75%——垄断定价。芯片层拿走了整条
  产业链利润的大头，这正是下游云厂自研 ASIC 的根本动机（06篇）；
- **资本强度**：fabless 模式，自己不建厂 → 高 ROIC，但完全依赖 TSMC（02篇）；
- **周期性**：表面是成长股，本质仍是半导体周期股——客户（云厂）的 capex
  是有周期的。NVDA 的收入 = 云厂 capex 的一阶导，**云厂 capex 增速放缓
  （不需要下降）就足以让本层收入增速腰斩**；
- **客户集中**：前四大客户占 NVDA 数据中心收入约一半——单一客户转向自研
  ASIC 的边际影响巨大。

## 关键跟踪指标

| 指标 | 频率 | 看什么 |

| 四大云厂 capex 指引 | 季度财报 | 本层收入的领先指标（总闸门） |

| AMD MI 系列大客户定点 | 新闻流 | 第二供应商逻辑兑现度 |

## 投资视角

- 本层是**共识最充分**的一层——NVDA 的垄断人尽皆知，"需求>>估值"的错位
  大概率不在这里，而在为本层供货的上游（02-05篇）；
- 但本层是所有上游分析的**前提变量**：上游每个标的的需求模型里都有
  "NVDA 出货量 × ASIC 出货量"这一项。跟踪本层不是为了买它，是为了
  给上游标的的需求做输入；
