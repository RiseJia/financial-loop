# 02 制造与封装层：摩尔定律放缓如何把价值挤进封装与材料

## 本层回答的问题

芯片是怎么被造出来的？为什么台积电无法被替代？为什么"先进封装"突然成了
2024-2026 年最紧的瓶颈？材料金字塔的底部藏着什么？

## 技术第一性原理

**制程 = 晶体管有多小**。3nm/2nm 指代晶体管的工艺代际，越小 → 同面积塞越多
晶体管 → 算力越强、功耗越低。但每前进一代：
- 研发成本指数级上升（一座 2nm 厂 >$200 亿）；
- 光刻步骤越来越依赖 EUV（极紫外光刻，ASML 全球独家），2nm 需要 25+ 层
  EUV（7nm 只要 5-10 层）——**设备与材料的用量随制程推进结构性增长**；
- 良率爬坡越来越难。

**摩尔定律放缓 → chiplet → 先进封装**（理解本层最重要的因果链）：
单颗大芯片越做越贵、良率越低 → 业界把大芯片拆成多颗小芯片（chiplet），
分别制造再"拼"起来 → **拼装的技术就是先进封装**。NVDA Blackwell = 2 颗
逻辑 die + 8 颗 HBM 拼在一块硅中介层上，用 TSMC 的 CoWoS 工艺。
**算力的瓶颈从"造芯片"部分转移到了"拼芯片"**——这就是 CoWoS 2024-2026
连续三年售罄、产能四倍化仍不够的原因。

**封装的材料栈**（自上而下，越深越垄断）：
```
GPU+HBM → 硅中介层(CoWoS) → ABF载板 → ABF增层膜 → T-glass玻璃布
            TSMC               四寡头     Ajinomoto95%   Nittobo~90%
                                              └涂布外包: ZACROS/Arisawa
```
载板是芯片与电路板之间的"转接桥"，AI 芯片越大、信号越密，载板层数从
3+3 走向 13+13——**面积×层数双重增长**，放大了整个材料栈的需求。

## 格局与玩家

- **代工**：TSMC 在先进制程（5nm 以下）份额 ~90%。垄断成因不是单点技术而是
  **万级工艺步骤的良率知识积累 + 苹果/NVDA 等大客户连续预付的资本循环**——
  三星良率追不上，Intel 代工转型中。地缘集中（台湾）是全产业链最大的尾部风险；
- **设备金字塔**：ASML（EUV 独家，5）→ AMAT/LRCX/KLAC/TER（沉积/刻蚀/检测/测试）
  → 封装设备（BESI/ASMPT/Hanmi/K&S，HBM 与 chiplet 的键合是当前争夺最烈的新增量）；
- **材料金字塔**：硅片五寡头（CR5≈89%）→ 光刻胶（信越/TOK/JSR）→ 特气
  （Linde/APD）→ CMP（ENTG）→ 石英（Spruce Pine 双矿垄断砂源，私有）；
- **OSAT（封测外包）**：ASE/Amkor/SPIL——TSMC 忙不过来时的外溢承接者，
  2026 年 TSMC 外包 24-27 万片 CoWoS，ASE 借机提价 5-20%（OSAT 史上罕见）。

详细玩家与数字见[产业链地图](../ai_supply_chain_map.md)①②节。

## 经济学特征

- **越往金字塔底部，垄断越极端、资本强度越低、利润率越高**：
  TSMC 重资产（年 capex $40B+）毛利率 ~55%；Ajinomoto 的 ABF 业务利润率 >50%
  且 capex 只要 ¥250 亿——**材料垄断者是整条链资本效率最高的生意**；
- **设备商的周期形态**：收入 = 客户 capex 的一阶导，弹性最大、拐点最猛。
  且内部高度分化（谁的机型进了下一代产线谁吃肉，见深度报告"设备四国杀"）；
- **代际跃迁创造新玩家窗口**：混合键合（hybrid bonding）取代传统键合、
  玻璃基板补充有机载板——每次技术代际切换都重新洗牌设备与材料份额。

## 投资视角

- 这一层是"需求>>估值"**最可能藏身的地方**：公司冷门（日本化工/纺织集团里的
  电子材料部门）、垄断极端、且需求有"面积×层数"的二阶放大。Tier 1 候选
  （Nittobo/Ajinomoto/Ibiden）全部出自本层——逐公司分析见
  [深度报告第二章](../../reports/research/2026-06-11_ai_upstream_deep_dive.md)；
- 镜像风险：本层也是**鞭子效应最猛**的一层。2022-23 年 ABF 载板刚经历过
  一轮"扩产撞上需求回落"的过剩（Unimicron 毛利率从 30%+ 摔到 15%），
  只隔三年。所有扩产故事都要问一句：2027 年新产能落地时，需求还在吗？
- 工具：`finloop screen --tier upstream` 横截面比较本层标的的增长/估值错位。
